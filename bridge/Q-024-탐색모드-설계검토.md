# Q-024 탐색 모드(복지로 서비스 목록 구조의 시흥 792건 전용 버전) 설계 검토 요청

사람 지시: 복지로 서비스 목록 구조를 시흥시 버전으로 모두 구현. 기존 디자인은 엎어도 됨(복지이음 브랜딩 유지, 복지로 로고·문구·이미지 복제 금지 — 구조·상호작용만 참고). 조사 자료: `reviews/bokjiro-benchmark-024.md`. 읽기 전용: `reviews/direction-024.md` 에만 쓸 것.

## 내 설계안 (검토·수정·거부해 달라)
- 라우트: `GET /resources` (서버 렌더 목록 + 필터 폼, 쿼리스트링 상태), 상세는 기존 `/resources/{id}`. 홈에서 "조건 입력(7단계)"과 "둘러보기" 두 진입점.
- 필터(복지로 3축을 우리 데이터 태그로 매핑, 소스 기준 설명 문구 표시):
  - 관심주제 = 우리 category 9종(JOB/HOUSE/DAILY/HEALTH/MIND/CARE/EDU/CULTURE/RIGHTS). 복지로 16주제를 억지로 만들지 않는다.
  - 생애주기(영유아 0-5·아동 6-12·청소년 13-18·청년 19-39·중장년 40-64·노년 65+, 임신·출산=household PREG): age_min/age_max 구간 겹침 OR 연령 힌트 집단어(기존 ageHintCond의 정규식 재사용)로 포함. 연령 태그 없는 자원은 '해당없음' 처리가 아니라 힌트 없으면 해당 생애주기 필터에서는 빠지고 '전체'에서만 보인다 → 화면에 "대상이 명시된 자원만 필터됩니다" 고지.
  - 가구상황(저소득=income_rank 1·2 또는 income 확인필요 아님, 장애인=disability Y, 한부모·조손=SPAR, 다자녀=MCHD, 다문화·탈북민=MCUL/NKOR 또는 nationality F, 1인가구=ONE): 태그 기반, 복수 선택은 OR.
  - 나이 입력(만 N세; 태그 구간 포함 + ±1 관용 안 씀), 동 선택, 검색어(name·support_content·org_name·applicant LIKE), 제외 검색어, 온라인 신청 가능(apply_url 있음), 지원주기/제공유형 표시(필터 아님).
  - 정렬: 기본(분야·이름), 최신순(data_base_date), 인기순(event_log D 클릭 수, 데이터 적음 → 동률은 기본순). 페이지네이션 12건/쪽(서버 렌더).
- 카드: 분야·가구 태그, 담당부서, 지원주기, 제공유형, 문의처, 기준일·오래된 자료 배지, 찜 버튼. 상세: 지원대상/서비스 내용/신청방법/추가정보 구조로 섹션 정리(기존 판정표·비교표는 유지).
- 찜: localStorage(서버 저장 없음, 개인정보 최소 원칙). `/resources?ids=1,2,3` 로 찜 목록 보기.
- 복지지도: 좌표 데이터 없음·지도 API 키 필요 → 이번 범위에서 제외(근거 문서화) 제안. 복지위기알림·신고 제외.
- 판정 로직 Java 복제 금지(SQL에서). 탐색 모드는 '자격 판정'이 아니라 '둘러보기'임을 화면에 명시, "나에게 맞는지 확인"으로 7단계 입력 유도.
- 태깅 원칙 충돌 여부, i18n(ko/en/zh/vi 라벨), 접근성, 모바일(390px).

2. 구현 작업 분해(PLAN-024 형식: T번호, 종류, 소유 경로, 의존, 완료 기준)와 wave. plan-check 호환 표.
3. 수락 기준(회귀 테스트 항목: SQL 필터 정확성 케이스, 스모크 항목).
