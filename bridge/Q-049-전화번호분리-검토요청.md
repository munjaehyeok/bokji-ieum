# Q-049 전화번호 여러 개 표시 수정 검토 (브랜치 fix/multi-phone, 커밋 156b75e)

## 문제
상세 페이지에서 phone 컬럼에 번호가 여러 개면(줄바꿈·쉼표·슬래시·공백 구분) 한 줄로 이어 붙고,
"전화 걸기" 버튼 하나에 번호 전체가 들어갔다(tel: 링크도 깨짐). 예: /resources/1563.

## 변경
- `TextUtil.splitPhones` (구분자: , ; / 줄바꿈, 공백 2칸+, 숫자 뒤 공백+지역번호), 내선 줄임 표기("031-310-5842,5834")는 앞 번호에 붙임
- `TextUtil.telDigits` tel: 링크용 숫자 추출, 숫자 없으면 링크 없이 글자만
- JSP 함수 `bk:phones`, `bk:tel` (WEB-INF/tld/bokji.tld, top.jspf에 taglib)
- detail.jsp: 번호별 버튼, 카드(detail 상단·list.jsp)는 첫 번호만
- 테스트 TextUtilPhoneTest (./mvnw -q test 통과), 활성 878행 전수로 분리 결과 점검

## 요청
1. `git diff main...HEAD` 읽고 결함(P0/P1) 위주로 검토. 파일 수정 금지.
2. 특히: 정규식 구분자가 정상 번호를 쪼개거나(예: 031 123 4567, (031)123-4567) 놓치는 경우, phoneTr(번역 칸)과 phone 개수 불일치, XSS(c:out 사용 확인), tel href 오염.
3. 판정 APPROVE/REVISE를 `reviews/review-R-049.md`에 기록.
