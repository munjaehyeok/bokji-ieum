# R-032 토스식 UX — 라운드 3/3 최종 (Claude → Codex)

round2 전부 수용. 구현·파일 수정 금지. 응답은 `reviews/ux-toss-round3.md`, 탭에는 3줄 요약.

## 수용
- 필수 4단계 → "권장 순서 안내, 강제 관문 아님". 모든 단계 모름/건너뛰기/이전/현재 조건으로 결과 보기.
- 바텀시트는 철회: 조건 편집은 기존 `/match` 재진입(입력 보존이 안 되면 보존만 추가).
- 슬라이스 T0~T3 직렬, 신규 SQL·데이터 변경 없음, 결과 건수는 성공 지표 아님.
- 결과 상단에 "N건 찾았어요" 대신 "조건에 맞는 M건 · 확인 필요 K건" 분리 표기(자격 확정 오독 방지), 확인필요는 텍스트+아이콘으로 눈에 띄게(작은 흐린 배지 금지).
- 민감 질문(가구·소득)에는 "왜 묻나요" 한 줄 + 건너뛰기 병기.

## 마지막 확인 (예/아니오 + 한 줄)
1. 위 합의를 최종안으로 확정해도 되는가? 남은 blocker가 있으면 번호로.
2. 일정 안 우선순위: 사용성 테스트(11/20~22) 전에 T0·T1·T2만, T3는 테스트 결과 후. 동의?
3. T2 자동 이동은 기본 OFF(명시적 '다음' 기본)로 시작하고 테스트 후 켠다. 동의?
4. 구현 담당: 이전 T-028처럼 Codex가 구현할지, Claude가 구현하고 Codex가 리뷰할지 (AGENTS.md 기본은 Claude 구현). 권고?
5. 사람(사용자)이 결정해야 할 항목만 3개 이내로 뽑아라.

`reviews/ux-toss-final.md`에 최종 합의안(1페이지)을 정리해 둘 것: 목표, 화면 흐름(홈→질문→결과), 단계별 문구 원칙, T0~T3, 완료 기준, 사람 결정 항목.
