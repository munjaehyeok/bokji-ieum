# R-022 평가조건 대비 다각도 검토

검토 기준일: 2026-10-22. 이는 **예상 점수표가 아니라 감점 위험 평가**다. 평가조건 원문은 `참고자료/평가조건.rtf`, 구현·검증 상태는 저장소의 2026-10-19 재집계와 현재 코드 기준으로 대조했다. 제안서 30%와 최종평가 70%를 구분한다. 평가조건 원문에는 제안서·영상의 10월 제출 안내가 함께 있으므로, 아래 11월까지의 조치는 **최종평가 대비**로 읽어야 한다. 실제 제출 일정은 수업 공지로 재확인해야 한다.

## 2. 차별성 판단과 권장 프레이밍

**현재 주장 그대로는 부족하다.** [README](../README.md)의 “복지온은 목록 검색에 그친다”는 표현은 시 공식 [복지온 접속점](https://www.siheung.go.kr/bokjion/)과 [시흥톡의 복지 상담 안내](https://talk.siheung.go.kr/)만으로는 입증되지 않는다. 복지온의 실제 기능을 동일 시나리오로 확인한 비교표가 없다. [복지로의 공식 안내](https://www.bokjiro.go.kr/ssis-tbu/twatvb/wlfareCust/selectFaqList.do)는 복지멤버십이 연령·가구구성·경제 상황으로 맞춤 안내를 제공한다고 명시한다. 따라서 “기존 서비스는 맞춤형 기능이 없다”는 비교는 쓰면 안 된다.

권장 문장은 “시흥시의 **기존 복지 정보 전달체계에 붙일 수 있는 설명형 사전 탐색·신청 연결 모듈**”이다. 복지온과의 연계는 현시점에 시의 협약이나 기술 통합이 확인된 것이 아니라, [화면 푸터](../src/main/webapp/WEB-INF/views/common/foot.jspf)의 외부 링크와 설계상 제안이다. 공식 앱 개선을 **완료했다**고 말하지 말고, “복지온에서 자격 확인 진입점 제공을 제안한다”로 말해야 한다. 복지로 대비 차이는 전국 서비스의 부정이 아니라 시흥 민간 546건을 포함한 지역 소스, 비회원 조건 입력, 항목별 설명과 최신성 구분을 **검증 가능한 범위**에서 제시한다. 546건의 내용이 최신이라는 의미는 아니다. 직접 비교 실험 전에는 우월성 표현을 보류한다.

## 4. 최종평가 증거와 운영 경계

- **이미 보여 줄 수 있는 것:** 2026-10-19의 활성 792건, 결정표 40/40, 6개 시나리오 6/6(설계 기준), 빈 DB 데이터 게이트, 회귀와 브라우저 스모크. 단, [검증표](../docs/검증/검증표.md)의 엄격 보조 기준은 4/6이고 S4·S6의 상위 5위 변별력은 약하다. 40/40을 “실제 자격 정확도 100%”로 바꾸면 안 된다.
- **데이터의 결정적 한계:** [발표숫자 10/19](../docs/검증/발표숫자.md)에서 본문 기준일 2022가 744건이고 12개월 경과가 745/792건이다. 연락처·존속 확인일이 있는 336건도 자격·금액 검증과 별개다. [본문검증로그](../docs/데이터/수집/본문검증로그.md)는 본문 대조 0건을 명시한다. ‘최신 시흥 복지 792건’ 대신 ‘시흥 자원 792건 수록, 본문 최신성은 항목별 표시’로 표현해야 한다.
- **사용자 효과는 아직 가설:** [발표숫자](../docs/검증/발표숫자.md)의 8/9 퍼널·30% 단축·평균 4.0·배포 URL/Lighthouse는 미측정이다. 11/20~22의 9명 테스트 계획은 사전 목표일 뿐 결과가 아니다. 기존 사이트 대비 동일 과제·순서 교차·표본 수·중도 포기자를 함께 보고해야 한다.
- **운영은 제안과 구현을 분리:** 관리자 CRUD·이력·제보는 구현됐지만 시 부서의 승인·계정·유지 예산은 미확인이다. 공공 API는 2026-10-14에 **일회성 대조**가 수행됐고 자동 주간 동기화 증거는 없다. 민간 546건의 전량 자동 최신화 경로도 없다. [운영 설계](../docs/설계/05-검증-운영-설계.md)의 분기 갱신·7일 SLA는 이관 **제안**으로 표기한다.
- **실배포 전 보안 선결:** [AdminInitializer](../src/main/java/com/ieum/bokji/service/AdminInitializer.java)의 13~31행은 빈 DB에 공개된 고정 관리자 자격증명을 생성한다. 로컬 시연 설명과 분리하고 실 URL 공개 전에 제거/변경·접근 통제를 검증해야 한다. 이는 정책 이관 신뢰도에도 직결된다.
- **다국어 범위:** [발표숫자](../docs/검증/발표숫자.md)의 `resource_i18n`은 en 10건뿐이며 zh/vi는 UI 문구 번역, 자원 본문은 한국어다. “4개 언어로 전체 792건 안내”라고 말하지 말고 “4개 언어 화면, 본문 번역은 제한적”이라고 명시한다.
