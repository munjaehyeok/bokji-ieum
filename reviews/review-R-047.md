# R-047 · 2025 하반기 안내서 전량 교체 재검토

**전량 교체 방향은 유지한다. 현재 산출물은 REVISE다.** 대표 오태깅과 기존 ID 재사용은 개선됐다. 다만 구체적인 매칭 오제외, 확인일 오표기, 공개·전환 경로가 남아 있다.

기존 `HEAD`, 현재 작업 트리와 근거 CSV를 대조하고 SQL의 자원 변경 부분을 메모리 내 SQLite에서 재생했다. `901/471/430/11`, 안내서 ID `1001–1853`, API·보조금24 ID `1854–1901`, 자료 기준일 연도 `2026/2025 = 47/854`, 영어 자원 번역 1행을 확인했다. 구현자가 보고한 MySQL·HTTP 회귀 PASS는 이번 읽기 전용 검토에서 독립 재실행하지 않았다.
