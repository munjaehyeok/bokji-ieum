# R-043 · 2025판 종합안내서 교체 검증

**현 단계의 seed 교체 보류에 동의한다. 검증 문서와 도구는 수정 후 PR로 올린다.** A는 대조 기준본으로 쓰고 B는 빠진 항목과 변경 후보를 찾는 데 쓴다. 기존 ID를 유지한 상태에서 동일성이 확인된 자원의 본문 갱신과 검증된 신규 자원의 추가를 각각 진행할 수 있다. 기존 목록에서만 보이는 자원을 종료 처리하려면 별도 근거가 필요하다.

## 추가 병합의 조건

1. 현행 7단계 적재 뒤 별도 갱신 SQL을 적용해 기존 792건의 ID와 참조를 보존한다. 동일 자원으로 확인된 건은 2025판과 API·보조금24·수기 검증 근거의 적용 시점과 필드별 우선순위를 확인해 갱신한다. 새 자료가 있다고 기존 자원의 기준일을 일괄 상향하지 않는다.
2. 새로 추가할 자원은 확인된 출처 식별자를 쓰거나 안정적인 대응 키를 부여한다. `resource`의 유일 제약은 ID이고, 두 기존 API 패치의 신규 행은 `INSERT … VALUES`다. 그대로 재사용하면 재실행 시 중복이 생길 수 있다. 원본 행 번호만으로 재발행본을 식별하면 행 이동에도 취약하다. 분할·통합, 동명 타기관, 기관명 변경, 기존 API·보조금24와 중복 후보를 검토하고 판단 근거를 CSV에 남긴다.
3. 빈 DB 전체 적재와 새 SQL 2회 적용을 검증한다. 자원 ID·본문·출처·태그가 같고 번역 및 참조가 보존되는지 확인한다. 실제 매칭 노출, 팀이 승인한 카테고리별 집계, 문서와 발표 수치까지 확인한 뒤 데이터 변경 PR을 검토한다. 기존 안내서에만 남은 자원은 담당부서의 종료 또는 개편 근거가 확인된 경우에 별도 조치한다.
