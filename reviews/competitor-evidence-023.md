# T2 복지온 직접 확인 (2026-10-23, Claude in Chrome, 합성 질문 1건)

대상: https://www.siheung.go.kr/bokjion/ → /bokjion/chat ("시흥복지-온(溫) 토로", 24시간 민원 응대 챗봇).
합성 입력: "67세 1인가구 기초생활수급자가 받을 수 있는 식사 지원은 무엇이 있어" (개인정보 없음). 캡처: `reviews/screens/competitor-bokjion-chat-20261023.jpg`.

| 항목 | 확인 결과 |
|---|---|
| 형태 | **자유 질문 챗봇**(목록 검색 화면이 아님). 안내문: "정확하거나 최신 정보를 반영하지 않을 수도 있습니다. 중요한 사항은 관련 기관에 확인" |
| 로그인 | 불필요(확인) |
| 조건 입력/자격 판정 | 구조화된 조건 입력 화면 없음(확인한 범위). 질문 문장에 연령·가구·수급을 적어도 응답은 사업 안내이며 항목별 일치/불일치 판정표는 없음 |
| 응답 | 시흥돌봄SOS센터 '식사지원', 경기도 기부식품등 제공사업 2건 안내 + 상세 링크 2개 + 후속 질문 버튼 |
| 신청 연결 | 상세보기 링크, 신청 방법 후속 질문 버튼 |
| 근거·기준일 표시 | 응답 본문에 기준일 표시 미확인(링크 제공) |
| 언어 | 한국어 화면(다국어 미확인) |
| 시흥 민간 자원 포함 여부 | 이번 질문에서는 공공 2건만 안내됨. 전체 범위는 **미확인** |

**복지로**(전국 서비스): 공식 FAQ상 복지멤버십이 연령·가구·경제상황으로 맞춤 안내를 한다고 되어 있고, 직접 조작 비교는 로그인이 필요해 **미확인**(실제 개인정보 입력 금지).

## 결론(문구 경계)
- README의 "복지온은 목록 검색에 그친다"는 **사실과 다르다**(복지온은 자유질문 챗봇). 이미 README를 교정했으며, 이후 문구는 "복지온은 질문에 답하는 챗봇 안내, 복지이음은 구조화된 조건 입력으로 항목별 일치/확인필요 근거를 보여 주는 보완 모듈"로 한정한다.
- 확인된 차이(3개 이내): ① 조건 입력→항목별 판정표(복지온 챗봇에는 판정표 없음, 확인 범위) ② 확인필요/기준일 표시 ③ 시흥 민간 자원 포함(복지온 범위는 미확인이라 '우월' 단정 금지).
- 복지온 챗봇은 답변을 생성하므로 같은 질문에도 답이 달라질 수 있다(1회 관찰, 재현성 미확인).
