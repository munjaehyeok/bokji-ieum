# R-029 복지로 디자인 이식 재리뷰

- 판정: **REVISE**
- 범위: 읽기 전용 검토. 코드·데이터·기타 문서는 수정하지 않음.
- 기준: `bridge/R-029-디자인이식-재리뷰.md`, `reviews/design-bokjiro-smoke-028.md`, `a99eaae`, `git diff 3ca85c9..HEAD -- src/main/webapp/static/css/bokji.css`.

## 요약

R-028 후속 기록에는 모바일 넘침, 글자 확대, 대비 측정과 회귀 재실행 결과가 기재되어 있고, CSS 변경은 색상 두 클래스에 한정되어 색상 의도 훼손 위험이 낮아 보인다. 로고/이미지의 복지로 원본 요소 재사용 증거는 확인되지 않았다. 다만 결과 화면의 두 접근성 그룹명이 영어 하드코딩이며, 대비·반응형 수치의 원시 측정 내역은 리뷰 기록에 없어 완전한 재검증은 불가능하다. 실제 키보드 순회·스크린리더 발화·인쇄 미리보기도 미검증으로 명시되어 있다.

## 지적 사항

### P2 — 결과 페이지 그룹 접근성 이름이 다국어화되지 않음

`src/main/webapp/WEB-INF/views/match/result.jsp`의 카테고리 필터와 정렬 컨테이너는 각각 `aria-label="category filter"`, `aria-label="sort"`를 직접 사용한다. 화면의 버튼/본문은 언어 선택에 따라 번역되지만 보조기술 사용자에게는 이 그룹 이름이 영어로 노출된다. R-029의 다국어 aria-label 확인 기준에 맞지 않는다. 병합 전 메시지 리소스를 사용하는 현지화 여부를 확인할 것.

## 근거 검토

- **CSS 범위/의도:** `3ca85c9..HEAD`의 `bokji.css` 차이에서 후속 접근성 보정은 `.text-secondary` 글자색과 `.btn-outline-secondary` 변형 색 변수에 한정된다. 배경/브랜드 토큰을 추가 변경하지 않는다. 기록의 4.38:1에서 약 5.9:1 개선 주장은 합리적이고, 흰색 버튼 텍스트의 hover/active 색은 어두운 회색이다. 다만 398쌍 측정의 각 색상 조합/산출 원자료가 보고서에 없어 제삼자가 전체 측정을 재현할 근거는 제한적이다.
- **복지로 식별 요소:** 변경 diff와 웹 자산을 읽어 보았으며, 복지로 상표명·공식 문구·캐릭터·사진 재사용을 찾지 못했다. `.bk-logo-mark`는 `icons.svg`의 자체 기하 도형 심볼이며 식별 로고 복제 근거는 없다. CSS 주석도 시각 구조만 참고하고 자체 구성 요소를 썼다고 설명한다. 원본 전체 화면 픽셀 대조는 기록상 수행되지 않았다.
- **접근성 구조:** 공통 헤더에 번역 메시지 기반 건너뛰기 링크가 있고, `:focus-visible` 표시와 `prefers-reduced-motion` 및 인쇄 스타일이 존재한다. 즐겨찾기/정렬/페이지 이동 등 주요 컨트롤의 일부 aria-label은 메시지 기반이다. 그러나 결과 페이지 그룹의 영어 이름은 위 지적과 같고, `close`, `examples`, admin 화면 등의 하드코딩 aria 이름도 남아 있다(일부는 공통 사용자 흐름 외 범위). 실제 키보드 포커스 이동·스크린리더 발화·인쇄 결과는 수행되지 않았다고 후속 기록에 정확히 적혀 있다.
- **레이아웃 수치:** 390px 16개 조합에서 넘침 0, 125% 확대 3화면에서 넘침 0이라는 결과가 기록되어 있다. 상세 경로, 결과를 포함한 구성과 측정 방법은 적혀 있지만 DOM별 폭 원자료는 포함되지 않아 요약 결과 수준으로만 신뢰 가능하다.

## 병합 전 확인

1. 결과 필터/정렬 그룹의 aria-label을 4개 언어로 제공하거나 이미 지원되는 다국어 레이블을 사용하도록 구현·재검증한다.
2. 결과 페이지의 키보드·스크린리더 확인을 추가하고, 대비 측정 원자료 또는 재현 가능한 측정 기록을 리뷰 증거로 보완한다.
3. 나머지 미검증 한계(실제 인쇄 미리보기와 원본 픽셀 비교)는 제품 승인자가 수용 가능한지 확인한다.

현재 근거만으로는 다국어 접근성 지적을 해소하지 못했으므로 병합 승인을 권고하지 않는다. 코드 수정은 하지 않았다.
