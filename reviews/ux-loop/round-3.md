# R-037 토스식 시각 검토 — 라운드 3 (최종)

## 범위와 근거

- `bridge/R-037-토스식시각검토-라운드3.md`, `reviews/ux-loop/REVIEWER-ROLE.md`, 라운드 2 리뷰를 기준으로 읽기 전용 검토했다.
- Chrome의 로컬 사이트를 약 1710px 데스크톱 폭에서 확인했다. 홈, 매칭 질문, 매칭 결과, 자원 둘러보기의 화면을 확인했고, 질문 답변이나 필터를 제출·변경하지 않았다. 화면 캡처 파일은 새로 저장하지 않았다.
- 홈은 한 줄 헤더와 좌측 텍스트·우측 일러스트, 화면 끝까지 이어지는 연한 배경을 보여준다. 라운드 2의 중국어 제목 잘림 및 히어로 카드 윤곽 지적은 현재 CSS의 `overflow-wrap`, 언어별 `word-break`, `.bk-hero` 배경 확장 규칙과 일치한다. 이 재검토에서는 4개 언어/모바일 폭 측정치를 독립 재실행하지 않았다.
- 데스크톱 결과 화면에서는 다른 세 화면과 달리 `처음부터 다시` 링크가 보이고 주 내비게이션이 두 번째 줄로 내려간 캡처/접근성 트리가 관찰됐다. 다만 현재 소스의 `@media (min-width: 992px)`에는 `.bk-nav-restart { display:none }`가 있다. 현재 표시 결과와 소스가 불일치하므로 브라우저의 캐시/실제 제공 CSS 여부를 별도 확인할 필요가 있다.
- 결과·둘러보기 카드에는 사업내용 기준일, 오래된 자료, 확인 필요 표기가 남아 있고, 최종 자격은 담당 기관 확인이라는 문구도 유지된다. 연락처 확인일이 사업내용 확인으로 오인되지 않도록 분리 표기된 점은 적절하다.

요청에 따라 모바일 폭 항목(⑧)은 총점에서 제외했다. 점수는 데스크톱 시각 검토 8개 항목 기준이다.

|---|---:|---|
| ① 헤더 | 3 | 홈·질문·둘러보기는 얇은 한 줄 헤더로 정돈됐다. 결과 화면은 `처음부터 다시`가 보이며 내비게이션이 두 줄로 갈라지는 모습이 관찰돼 페이지 간 일관성이 부족하다(소스 CSS와 불일치). |

## 남은 격차와 제안

### P2 — 결과 페이지 데스크톱 헤더 상태 불일치 확인

- 근거: 라이브 결과 화면 캡처/접근성 트리에서 `처음부터 다시`와 별도 내비게이션 행이 보인다. 같은 화면의 홈은 한 줄 내비게이션이다. `top.jspf`에서 링크는 `href="/"`이고 CSS에는 데스크톱에서 숨기는 규칙이 있으므로, 실제 조건 초기화 기능은 아니다.
- 대상: `src/main/webapp/WEB-INF/views/common/top.jspf`의 `.bk-nav-restart`; `src/main/webapp/static/css/bokji.css`의 `@media (min-width: 992px)` 헤더 규칙.
- 제안: 사람이 보는 결과 탭에서 최신 CSS가 실제 반영됐는지 확인한다. 링크가 실제로 표시되고 줄바꿈을 유발한다면, 승인된 기존 방향대로 데스크톱에서 숨기고 홈/조건 수정/둘러보기의 핵심 탐색을 유지한다. 숨김을 조건 초기화로 설명하지 않는다. 캐시된 화면이면 코드 변경 없이 닫는다.

### P2 — 홈 설명 섹션의 패널 밀도

- 근거: 홈 첫 화면의 열린 히어로 뒤에 중앙 정렬된 큰 라운드 패널이 이어져 섹션 전환이 강하다. 기능상 문제는 없고, 설명 카드 3개의 위계도 읽힌다.
- 대상: `src/main/webapp/static/css/bokji.css`의 `.bk-how` 및 `.bk-how-card`.
- 제안: 현재 시각 언어로 멈춰도 된다. 추가 조정을 하더라도 설명 패널의 틴트/반경을 낮추거나 내부 콘텐츠 폭을 넓히는 정도로 제한하며 카드 정보와 여백을 유지한다.

## 모바일 범위 별도 기록

모바일 헤더 압축, 고정 페이지 이동 버튼 겹침, 결과 필터/건수 배치는 R-037이 명시한 사용자 범위 제외에 따라 이번 시각 라운드의 미완료 P2로 남긴다. 모바일 화면이 깨지지 않는지에 대한 게이트는 시각 적합성 점수 제외와 별개이며, 팀의 배포 기준에서 여전히 요구한다면 독립 브라우저 스모크로 확인해야 한다. 이 검토에서는 모바일 화면을 재채점하지 않았다.

## 하지 말아야 할 것

- 모바일 범위 제외를 근거로 텍스트 잘림·키보드 접근·대비·터치 영역의 필수 품질 게이트를 해제하지 않는다.
- 입력 7단계, 매칭/데이터 계약, 시흥시 자원만 수록 원칙을 시각 변경과 함께 바꾸지 않는다.
- 결과의 `일치`, `추가 확인 필요`, 오래된 자료, 연락처 확인일/사업내용 기준일을 자격 확정 또는 사업내용 최신 검증처럼 표현하지 않는다.
- Toss 로고·전용 서체·이미지·문구·상표를 복제하지 않는다.

## 최종 판정

**시각 방향은 여기서 멈춰도 된다 (APPROVE, 알려진 P2 기록 포함).** 라운드 2의 두 P1은 구현 근거상 해소됐고 홈 히어로는 원하는 열린 구성이 됐다. 다음 시각 반복 라운드는 필요하지 않다. 다만 결과 헤더는 라이브 표시와 현재 CSS가 서로 달라, 결과 탭에서 제공 중인 CSS를 확인하고 캐시 차이인지 실제 회귀인지 한 번만 판별할 것. 실제 회귀여도 P2이며, 범위가 다시 열릴 때 링크 표시/줄바꿈을 정리하면 된다. 이번 판정은 병합·배포 승인이 아니고, 프로젝트의 브라우저/접근성 게이트를 대신하지 않는다.
