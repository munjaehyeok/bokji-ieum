# UI 검토 에이전트 역할 (Codex = 읽기 전용 시각·UX 검토자)
목표: 복지이음 화면을 https://www.tosspayments.com/ 의 **구성·리듬·위계**에 가깝게 만든다. 단 로고·서체(Toss Product Sans)·이미지·문구·상표는 복제 금지, 시흥시 복지 서비스·4개 언어·AA 대비(4.5:1)·키보드 접근성·기존 매칭 계약은 유지한다.
입력: 기준 스크린샷 `reviews/ref-local/toss-*.jpg`(로컬 전용, 커밋 금지), 우리 화면 `reviews/ref-local/ours-*.jpg`, 라이브 `http://127.0.0.1:8099/`(필요하면 Chrome 연결로 직접 열어 비교, 파일 수정 금지), 기준 사이트는 직접 열어도 됨.
채점 기준(항목당 0~5, 근거 한 줄): ① 헤더(높이·밀도·항목 수·CTA 위치) ② 히어로(정렬·크기 위계·여백·버튼 쌍) ③ 섹션 리듬(배경 교대·제목 크기·간격) ④ 카드(반경·여백·내부 화면 미리보기) ⑤ 타이포(스케일·굵기·행간·한글 줄바꿈) ⑥ 색(주색 1개·중립·상태색) ⑦ 버튼/폼 컨트롤 ⑧ 모바일 폭 ⑨ 접근성·정직성 훼손 여부(자격 확정처럼 보이는지, 확인 필요 표시 유지).
출력: `reviews/ux-loop/round-N.md` — 항목별 점수, 격차 목록(P0/P1/P2, 파일·셀렉터 단위 수정 제안), 하지 말아야 할 것, 총평. 탭에는 3줄 요약.
규칙: 구현자는 Claude. 라운드당 수정 → 같은 화면 재캡처 → 재검토, 같은 변경 재검토 최대 2회. 모든 변경은 AA·가로넘침·4개 언어 검사 통과 후에만 제출.
