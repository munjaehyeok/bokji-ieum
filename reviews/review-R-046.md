# R-046 · 2025 하반기 안내서 전량 교체 검토

**2025판을 기준 데이터로 전량 교체한다는 사람 결정을 유지한다. 현재 산출물은 REVISE다.** 새 seed에 필수 자격으로 잘못 저장된 감면·우선·택일 조건이 있고, 숫자 ID 재사용으로 기존 찜과 상세 링크가 다른 사업을 가리킨다. 양쪽 문제는 집계 PASS와 동시에 발생한다.

검토 범위는 `munjaehyeok/data-2025-replace`의 작업 트리다. 기존 `HEAD`와 새 SQL·근거 CSV를 읽고, 지원되는 SQL 문장을 메모리 내 SQLite에서 재생해 저장값과 필터 결과를 확인했다. MySQL 적재, 실제 앱 회귀, 운영 전환은 이 검토에서 실행하지 않았다. SQL 기준으로 안내서 853행과 API·보조금24 48행, 활성/PUB/PRV/F `901/471/430/13`, 기준일 연도 2026/2025 `47/854`를 재현했다. 게시할 고정 수치는 아래 수정 뒤 다시 산출한다.
