# 번역 규칙 (시흥시 복지자원 안내 웹서비스 — 한국어 → en/zh(간체)/vi)
- 입력: /home/claude/tr/batch/NN.json = [{"h": 해시, "src": 한국어 원문, "f": 사용되는 필드명}]
- 출력: /home/claude/tr/result/NN.json = {"<h>": {"en": "...", "zh": "...", "vi": "..."}, ...}  (모든 h 빠짐없이, 3개 언어 모두 비어 있으면 안 됨)
- 독자: 시흥시에 사는 외국인 주민. 쉽고 자연스러운 문장. 공공 복지 안내문 어조(영어는 plain English).
- 원문의 줄바꿈(\n), 번호(①②, 1. 2.), 기호(○ - · ※), 숫자, 금액, 전화번호, URL, 영문 약어는 그대로 유지. 줄 수·순서 바꾸지 말 것. 요약·생략·추가 금지.
- 필드(f) 힌트: name=사업명(짧은 제목형), org_name/dept_name=기관·부서명, address=주소(영어는 도로명 로마자 표기 + 번역 병기 가능, 한자·베트남어는 자연스럽게), support_content=지원 내용, apply_method=신청 방법, documents=구비서류, eligibility_raw=지원 기준, cost_amount=본인부담, uncertain_note=조건 요약.
- 용어집(일관되게):
  시흥시 en Siheung City / zh 始兴市 / vi Thành phố Siheung
  복지로 Bokjiro(the national welfare portal) / 정부24 Gov24 / 주민센터(행정복지센터) community service center (dong office) / 보건소 public health center
  기초생활수급자 recipients of National Basic Livelihood Security / 차상위계층 near-poor households (low-income bracket just above the basic-livelihood line) / 기준 중위소득 standard median income
  장애인 persons with disabilities / 다문화가족 multicultural families / 한부모가족 single-parent families / 결혼이민자 marriage migrants
  신청권자 applicant / 선정 selection / 바우처 voucher / 현금 cash / 현물 in-kind
- 한국어 기관 고유명은 영어는 "로마자 표기 + 번역(필요 시)" 예: 시흥시청 → Siheung City Hall. zh/vi 도 자연스러운 번역, 로마자 병기는 필요할 때만.
- 결과 파일의 한국어(한글)는 가능한 남기지 말 것(고유명 로마자 표기로 대체). 번역 불가한 코드·URL 제외.
- 작업 후 python 으로 json 로드 확인, 입력 h 개수와 일치하는지 확인하고 끝에 "NN done: X items" 한 줄만 보고.
- 추가 필드 힌트: applicant=신청권자(누가 신청할 수 있는지, 짧은 구), service_cycle=제공시기/모집시기(예: 3월~12월 → Mar–Dec / 3月~12月 / Tháng 3–12), decision_period=선정 소요기간(숫자만 있으면 '일' 단위이며 그대로 두지 말고 문맥을 살려 "N days" 등으로; 오타로 보이는 값은 의미를 살려 번역; 전화번호처럼 번역 불필요한 값은 그대로 복사).
