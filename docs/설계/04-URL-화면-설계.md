# 04. URL·화면 설계

## 1. URL 명세

### 공개 (비회원, 로그인 불필요)

| 메서드 | URL | 처리 | 뷰/응답 |
|---|---|---|---|
| GET | `/` | 랜딩, 언어 선택 | index.jsp |
| GET | `/match` | 조건 입력 폼 (스텝 UI) | match/form.jsp |
| POST | `/match` | 조건 검증→세션 저장→리다이렉트 (PRG) | redirect:/match/result |
| GET | `/match/result` | 세션 조건으로 매칭 실행 | match/result.jsp |
| GET | `/match/result/list` | AJAX: 분야 필터/가구원 탭 전환 | JSON |
| GET | `/resources/{id}` | 상세 (판정표+신청 안내 통합) | resource/detail.jsp |
| POST | `/reports` | AJAX: 오류 제보 | JSON |
| POST | `/events` | AJAX 비콘: 신청안내 확인(A) — 전화·신청URL·인쇄 클릭 시 | JSON |
| GET | `/news` | 새 소식 (권장) | news/list.jsp |
| GET | `*?lang=ko·en·zh·vi` | LocaleChangeInterceptor | 세션 로케일 변경 |

세션 키: `matchCondition` (가구원 리스트 포함). 조건 없이 `/match/result` 접근 → `/match` 리다이렉트.

### 회원 (선택): `/signup /login /logout /mypage` + POST `/favorites/{resourceId}` (토글, AJAX)

### 관리자 (`/admin/**` 인터셉터 차단)

| 메서드 | URL | 처리 |
|---|---|---|
| GET/POST | `/admin/login` | 로그인 (5회 실패 잠금) |
| GET | `/admin/resources` | 목록: 검색(이름·기관), 상태·기준일경과 필터, 페이징 |
| GET/POST | `/admin/resources/new` | 등록 (등록 즉시 매칭 반영 = M6 완료 기준) |
| GET/POST | `/admin/resources/{id}/edit` | 수정 (저장 시 RESOURCE_HISTORY 기록) |
| POST | `/admin/resources/{id}/status` | 노출/숨김/종료 전환 |
| GET | `/admin/reports` · POST `/admin/reports/{id}` | 제보 목록·상태 처리 |
| GET | `/admin/stats` | 이용 통계 (선택): 조건 분포, 퍼널, 인기 자원 |

## 2. 화면 흐름 (제안서 6단계의 구현 매핑)

```
[1 랜딩 /] → [2 조건입력 /match (7스텝)] → [3 결과 /match/result]
                      ▲    (가구원 추가·조건 수정)      │ 카드 클릭
                      └────────────────────────┐      ▼
                                   [4·5 상세+신청안내 /resources/{id}]
                                      │ tel: 전화 │ apply_url │ 제보 │ 인쇄
[6 알림(선택)] ← 회원가입 ← 결과/상세의 "저장하려면 가입" 배너
```

## 3. 와이어프레임 (8종)

공통 레이아웃: 상단바(로고 이음 | 언어 ko·en·zh·vi | [처음부터 다시]) / 푸터(출처·기준일 안내, "참고용 안내—최종 자격은 담당기관 확인", 복지온·웰인포 링크 = 기존 시 서비스 연계).

### ① 랜딩 `/`
```
┌──────────────────────────────────────┐
│  복지이음        한국어|EN|中文|Tiếng Việt│
│                                      │
│   나에게 맞는 시흥시 복지, 1분 안에     │
│   744개 자원 · 로그인 없이 · 무료       │
│                                      │
│        [ 내 복지 찾기 시작 → ]  (큰버튼) │
│                                      │
│  "입력하신 정보는 저장되지 않습니다"      │
│  ────────────────────────────        │
│  이런 분들이 찾고 있어요: 어르신 돌봄 ·   │

### ② 조건 입력 `/match` — 한 화면 = 한 질문 (어르신 접근성)
```
┌──────────────────────────────────────┐
│  ●●●○○○○  3 / 7                      │
│                                      │
│  Q3. 가구 상황을 골라주세요 (복수 선택)  │
│  [1인 가구] [한부모·조손] [다자녀]       │
│  [다문화]   [임신·출산]  [북한이탈]      │
│  [해당 없음]                          │
│                                      │
│  [← 이전]            [모름/건너뛰기]    │
│  ───────────────────────────────     │
│  (마지막 스텝) + 가구원 추가하기 (선택)   │
└──────────────────────────────────────┘
```
스텝: 1출생연도(숫자패드) 2거주동(드롭다운+모름) 3가구 4소득(기준금액 도움말 팝업) 5장애 6국적/체류 7학업·취업 → [결과 보기]. 모든 스텝 '모름' 가능, 뒤로가기 시 값 유지(세션).

```
┌──────────────────────────────────────┐
│ 노인맞춤돌봄서비스            [공공]    │
│ ◆ 지원 내용  ……                       │
│ ◆ 나의 자격 판정                       │
│   연령 65세↑   ✅ 일치 (67세)          │
│   가구 1인가구  ✅ 일치                │
│   소득 중위100↓ ⚠️ 확인 필요(세부기준)   │
│ ◆ 신청 방법  주민센터 방문 / 전화        │
│ ◆ 준비 서류  신분증, … (없으면 '기관 문의')│
│ ◆ 담당 기관  노인복지과 [📞 031-310-xxxx]│
│ ◆ 출처: 시흥시 복지자원 종합안내서       │
│   기준일 2022-12 · 최근확인 2026-11     │
│ [🖨 인쇄] [정보가 다르면 알려주기] [저장★]│

### ⑤ 오류 제보 모달 — 텍스트 1칸(500자)+보내기. 개인정보 입력란 없음 명시.
### ⑥ 관리자 자원 목록 — 검색/필터(상태·기준일 12개월 경과)/[신규 등록], 행: 이름·기관·상태·기준일·수정
### ⑦ 관리자 등록·수정 폼 — RESOURCE 전 컬럼 + 태깅 7필드(드롭다운·체크박스로 입력, 자유 텍스트 금지), 저장 시 이력 기록
### ⑧ 관리자 제보 처리 — 제보 내용·대상 자원 링크·상태 변경(접수→확인→반영/반려)+메모

## 4. 다국어 설계

- `SessionLocaleResolver` + `LocaleChangeInterceptor(paramName="lang")`, 지원: ko(기본)/en/zh/vi.
- `messages_{lang}.properties`: UI 라벨 전부 + 판정 태그(tag.AGE=연령 …) + 분야·가구·소득 선택지. **자원 콘텐츠는 한국어 기본**, RESOURCE_I18N 있는 71건은 명칭·요약 번역 표시(권장).
- 외국어 로케일에서는 nationality='F' 자원을 동점 시 우선 정렬(ORDER BY에 로케일 보정 1항 추가).
- 번역 제작: ko 파일 확정(6주차 초) → 기계번역 초벌 → 다문화센터 또는 유학생 지인 감수 1회(D 담당). 감수 못 받으면 "기계번역 안내" 문구 병기.

## 5. 접근성 (어르신 타겟 — 완성도 점수 차별 요소)

- 기본 글자 16px 이상, 본문 대비 4.5:1 이상, 터치 타깃 44px 이상, 상단 [글자 크게] 토글(±2단계, 세션 유지).
- 조건 입력은 키보드/탭 순서 보장, 라디오·체크박스에 label 연결, 이미지 대체텍스트.
- 점검 도구: Lighthouse 접근성 90점 이상을 7주차 QA 완료 기준에 포함(D 담당).
