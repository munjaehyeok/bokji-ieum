# 07. 탐색 모드 계약 (`GET /resources`) — R-024/direction-024 반영

복지로 서비스 목록의 구조(3축 체크 필터 + 나이·지역·검색어·제외어 + 정렬 + 찜)를 시흥 792건 전용으로 구현한다. **자격 판정이 아니라 둘러보기**다(화면에 명시, 판정은 7단계 입력). 복지로의 로고·문구·이미지는 쓰지 않는다. 판정 로직은 Java에 복제하지 않고 SQL(resource-mapper.xml `browse`)에서 필터링한다.

## 쿼리 계약 (잘못된 값은 무시, 400/SQL 오류 없음)
| 파라미터 | 값 | 의미 |
|---|---|---|
| cat (복수) | JOB·HOUSE·DAILY·HEALTH·MIND·CARE·EDU·CULTURE·RIGHTS | 관심주제 = DB category 그대로 |
| life (복수) | INF 0–5 · CHD 6–12 · TEEN 13–18 · YOUTH 19–39 · MID 40–64 · SENIOR 65+ | 명시된 연령 범위(age_min/age_max)와 **구간 겹침**, ±1 관용 없음 |
| hh (복수) | LOW · DIS · SPAR · MCHD · MCUL · NKOR · ONE · PREG · FOR | LOW=income_rank 1·2 (incx=1이면 income_uncertain='Y' 포함) · DIS=disability='Y' · FOR=nationality='F'(**다문화·탈북민과 분리**, F 태그 정확도 미확정이라 별도 항목) · 나머지=household_types 코드 |
| age | 0–120 정수 | 만 N세가 명시 범위 안(±1 없음) |
| strict | 1 | 연령 태그 없는 자원 **제외**. 기본(없음)=포함 — 연령 미기재 자원이 필터에서 조용히 사라지지 않게 |
| incx | 1 | LOW 선택 시 소득기준이 복잡한(income_uncertain='Y') 자원도 포함 |
| dong | 행정동 코드 | dong_codes 비어 있으면(시 전체) 포함, 있으면 해당 동 포함 자원 |
| q | 공백 구분 ≤5단어 ≤30자 | name·번역명·support_content·org_name·applicant 에 **모든 단어**(AND) 포함, `% _ \` 리터럴 |
| xq | 동일 | 하나라도 포함하면 제외(**검색어보다 우선**) |
| online | 1 | "온라인 신청 안내 있음": apply_method에 온라인/인터넷 신청/복지로/정부24/e보건소/누리집·홈페이지 신청 문구 (apply_url만으로는 아님) |
| ids | 숫자 CSV ≤50 | 찜 목록(활성 자원만) |
| sort | (없음)=이름순 · latest · popular | latest=기준일 내림차순(NULL 마지막) · popular=상세 조회(D) 수, **표본 30건 미만이면 이름순으로 대체**하고 안내 |
| page | ≥1 (기본 1), 12건/쪽 | 범위 밖은 1~마지막 쪽으로 보정 |
- 축 안은 OR, 축 사이는 AND. 모든 정렬은 resource_id 동률키. 상태 A(활성)만.
- 필터 미기재(기본) = 792건 전체.

## 한계(화면에도 고지)
태그가 있는 자원만 해당 필터에 정확히 걸린다(연령 태그 273/792, 가구 102, 장애 181 등). 인기순은 익명 상세 조회 집계라 신청·선호도가 아니다. 지도·위기알림·신고는 이번 범위 제외(좌표 데이터·시 운영 영역).
