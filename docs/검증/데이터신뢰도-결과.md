## T8 점검 결과 (소득 구간 밖 rank, 확인필요 전달)
- 중위 180% 이하를 `rank=4 + income_uncertain=Y`로 둔 사업 28건(예: 발달재활서비스 계열, 고위험 임산부 의료비): 소득입력 0~4 **모두에서 노출**(제외 없음), 차상위(2)는 `소득` 일치 + `소득 세부기준 확인`, '그 이상'(4)은 일치가 아닌 `소득` 확인필요로 표시됨을 실제 매퍼로 확인. 결함 없음 → 현행 태깅 유지(보정 SQL 없음). 단, `태깅-현황.md:63·80`의 서술과 D4 규칙('구간으로 환원 안 되면 rank 비움')이 문서상 충돌하므로 규칙 문구 정리는 필요.
- `rank=NULL + uncertain=Y` 23건: 모두 `uncertain_note` 보유(0건 누락) → `NOTE` 태그 '추가 조건 확인'으로 전달됨을 노인일자리 사례로 확인.
- 연령 태그 보유 273건 중 33건은 이미 '연령 기준 복수' 메모(넓은 범위 채택). 메모 없이 대상이 여러 갈래로 보이는 **휴리스틱 후보 36건**을 `docs/데이터/수집/위험태깅점검.csv`에 목록화 — **미점검**이며 오태깅 확정이 아니다(예: id 115는 '수급권자 2) 만60세 이상' 번호 열거가 OR/AND 어느 쪽인지 원문 확인 필요).
