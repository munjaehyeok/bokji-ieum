# 매칭 결정표 단위 테스트 케이스 (기대값 선작성)

- 작성 기준: `설계/03-매칭-엔진-설계.md` §1~2 판정 결정표 + §2 "판정 보충 규정(2026-10-13 확정)" **만** 사용. 구현 SQL 미참조(구현 전 작성, 2026-10-13 / 보충 규정 반영 갱신 동일자).
- 모름/해당없음 입력 규약(보충 Q2): 가구형태·학업/취업은 **빈 값=모름(확인필요)**, **명시적 'NONE'=해당없음(제약 자원 불일치)**.
- 나이 계산: 당해연도(2026) − 출생연도. 가중치: 연령3 · 장애3 · 국적3 · 가구2 · 소득2 · 학업취업2 · 동1.
- 가상 자원은 `fixtures.sql`의 resource_id 9000번대(TEST- 접두사). 아래 "자원" 열은 그 ID.
- 표기: 포함=결과 목록에 나타남, 제외=WHERE에서 탈락. matched/needCheck는 기대 태그 CSV. 점수는 일치 조건 가중치 합(확인필요·무관은 0점).
- 미기재 사용자 필드는 전부 "모름/미입력"이 아니라 **해당 자원이 안 보는 조건**이라 무관임(각 케이스 자원은 검증 대상 조건만 제약을 가짐).

- 연령 경계 min−1/min/max/max+1 + 양측 ±2 불일치 + 미입력 + 한쪽 경계만(Q3) ✔ / 소득 4×5 전 칸 ✔ / 국적 K×F=확인필요 ✔ / 가구·학업 교집합·교집합없음(Q1)·NONE(Q2)·빈 값(Q2) ✔ / '모름' 전 필드(CMB-03) ✔ / income_uncertain 병기(INC-06)·모름 시 미병기(INC-07, Q5) ✔ / uncertain_note 태그(CMN-02) ✔ / 조합 점수 합산(CMB-01~03) ✔ / 무관(CMN-01, HH-05) ✔
