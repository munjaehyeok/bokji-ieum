## 1. 기동 (이 Mac 기준, 이미 셋업됨)

```bash
# DB (이미 실행 중이면 생략)
docker start bokji-mysql          # mysql:8, 127.0.0.1:3306, bokji/bokji11, db=bokji
# 데이터 재적재가 필요할 때만:
docker exec -i bokji-mysql mysql --default-character-set=utf8mb4 -ubokji -pbokji11 bokji < 데이터/schema.sql
docker exec -i bokji-mysql mysql --default-character-set=utf8mb4 -ubokji -pbokji11 bokji < 데이터/seed.sql
docker exec -i bokji-mysql mysql --default-character-set=utf8mb4 -ubokji -pbokji11 bokji < 데이터/api-update-20261014.sql        # 복지로 API 최신화분
docker exec -i bokji-mysql mysql --default-character-set=utf8mb4 -ubokji -pbokji11 bokji < 데이터/facility-refresh-20261014.sql  # 시설현황 대조(연락처 59건)

# 앱
cd bokji-ieum && ./mvnw cargo:run      # Tomcat 9, http://localhost:8080
```

팀원 셋업: `bokji-ieum/SETUP.md` (docker compose + mvnw, Maven 설치 불필요)

## 3. 시연 경로 (발표 데모 순서 추천)

1. **랜딩** `/` — 언어 4종 버튼, [글자 크게] 토글, "입력 정보 미저장" 고지
2. **조건 입력** — [내 복지 찾기 시작] → 7스텝 (시나리오 S1: 출생연도 1959 → 정왕본동 → 1인 가구 → 기초생활수급 → 장애 없음 → 내국인 → 해당없음). 아무 스텝이나 [모름/건너뛰기] 가능, 마지막 스텝에서 [가구원 추가] 시연 가능
3. **결과** — 1위 "홀몸어르신친구만들기"(8점) 등. 카드의 ✅일치(연령·거주 동·가구·소득) / ⚠️확인 필요 태그 = **추천 이유**, '오래된 자료' 뱃지(2022 기준일 — 정상 동작), 분야 필터 탭, 조건 [수정]
4. **상세** — 자격 판정표(일치/확인필요/불일치 행별), 신청 방법·서류·연락처(tel: 링크), 출처·기준일, [인쇄], [정보가 다르면 알려주기](제보 모달), 하단 "참고용 안내—최종 자격은 담당기관 확인"
5. **다국어** — 우상단 EN/中文/Tiếng Việt 전환 → 전 화면 번역 + 외국인 대상 자원 우선 정렬 (S6: 1996년생·외국인·매화동·구직 → 1위 "결혼이민자 취업교육")
6. **관리자** — 자원 검색·수정(수정 즉시 매칭 반영 시연: age_min 바꾸면 결과에서 사라짐/나타남), 변경 이력 자동 기록, 제보 처리(접수→확인→반영), '기준일 경과' 필터
7. **가구원 매칭** (여유 시) — S5: 다문화 + 자녀 2명 → 탭 분리, 자녀 탭 1위 "지역아동센터 방과후 돌봄"
